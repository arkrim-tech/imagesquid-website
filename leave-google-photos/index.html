Leave Google Photos without losing metadata

ImageSquid can bulk-import from most major commercial photo managers. The copy keeps originals, dates, and the rest of the metadata with the files. An OCFL export is how you can leave ImageSquid later, too.

What the bulk import keeps

Moving a full library can take a while, because of network and computing limits. ImageSquid import recovers from errors, picks up where it left off without starting over, and runs quietly in the background. It does this without blocking or locking active use of the app, and every file is copied at 100% fidelity.

Descriptions, dates, edits, relationships, organization, and source context stay with the files, not trapped only on the service you are leaving. Originals, edits, and metadata stay exportable if you quit the app or the hosted service.

How you leave ImageSquid too

You can leave a hosting provider, work offline, and leave ImageSquid — the app and any optional sync or backup service — at any time, without losing original media, later enhancements, or metadata enrichment.

On disk, ImageSquid files are archival OCFL objects (Oxford Common File Layout). Files on disk are the canonical source. Export tools make a convenient bulk copy of the library. From that OCFL bundle you can start a fresh copy of ImageSquid, browse and navigate the collection with your own filesystem tools, or build new applications on top of the OCFL object store.

You do not need ImageSquid installed to read a completed library. You can inspect it with ordinary file tools and rebuild it in full if the application or its indexes are corrupted or removed.
